# ADR-0007：材料要求模板的私有文件快照

CAAU-005 模板文件管理，基线 `d125828`，分支 `codex/caau-005-template-files`。

- 模板是总部发布前附加到某项材料要求的可选文件，不是承办方 `FileUpload`，不进入草稿、提交或审核附件。
- 新增 `TemplateUpload` 草案元数据和 `TemplateAttachment` 发布快照关联。对象键由服务器 UUID 生成；原文件名仅为安全显示/下载元数据。草案中每项材料最多一个模板，替换必须先删除旧草案绑定再新建；移除只解除记录，绝不将原文件名作为路径。
- 发布事务重新校验草案模板均已确认、属于当前要求材料、字节/哈希仍有效；创建 `RequirementVersion` 后创建附件快照。数据库禁止快照关联修改或删除，已发布任务不能创建/确认/移除模板，旧版本不会被悄然换掉。
- 草案模板上传/移除仅本任务赛事管理员且仅 DRAFT。发布后模板信息/字节下载仅当前任务被指派机构的 active ORGANIZER；审核员、赛事管理员、SYSTEM_ADMIN、其他组织、撤权旧经办人和未认证请求均拒绝。每次 info/content 都在事务中重新鉴权并确认是发布快照。
- 文件格式、字节、SHA-256、私有存储写入和确认沿用当前能力、签名验证、10 MiB 上限及 no-store/nosniff 下载头；不是模板库、病毒扫描、生产对象存储或版本升级机制。
- Web 草案页提供每项上传、确认、移除及可恢复错误提示；发布任务前明确模板随当前要求冻结。Web 和 Taro 任务详情显示安全原名、通过鉴权下载。Taro 编译/请求替身不构成微信开发者工具或真机验证。

验收：隔离真实 PostgreSQL/Chromium 覆盖上传/确认/移除/失败、发布快照及发布后不可换、跨组织/system/撤权拒绝、历史版本/旧文件保留、Web 和 Taro 编译；开发库追加迁移并证明旧数据及 migration checksum 未改。
