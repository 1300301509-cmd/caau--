# ADR-0017：赛事情况人员快照

状态：CAAU-045 实施。

## 决策

赛事情况不复制赛程，读取 `EventSchedule.matches` 作为日历和场次来源。参赛名单存于 `EventTeamRoster`，以赛事球队为边界；场次工作人员存于 `EventMatchStaff`，以 `eventId + scheduleRevision + matchId` 唯一定位。两类记录均使用 CAS revision，并追加不可变版本。

工作人员只允许登记到当前已发布赛程。赛程调整会回到草稿，重新发布后产生新 revision，因此旧工作人员记录不会混入新安排。参赛名单不读取或同步球队主档案成员，保持用户要求的比赛数据隔离。

## 结果

总部可从一份稳定的比赛快照查看当届人员，同时保留未来承办方小程序的写接口。代价是新赛程版本需重新确认工作人员；这是避免静默错配的明确选择。比分和实时统计以后使用独立模型扩展，不写入这两类人员快照。
