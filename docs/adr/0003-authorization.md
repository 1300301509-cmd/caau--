# ADR-0003：首版权限与本地身份

状态：CAAU-004 采用；依据 [首版规格](../product/mvp-material-review-spec.md)。

- 身份为内部用户，角色附着于组织成员；停用用户/成员立即影响后续请求。赛事授权显式关联成员，系统管理员无隐式赛事权限。
- EventScope / TaskScope 仅存权限锚点，不包含赛事详情、任务要求、提交内容或状态机。CAAU-005 必须在事务中关联锚点，不能以调用者传入的组织/赛事 ID 替代数据库归属。
- 任务经办人与审核员均引用同赛事授权（复合外键）。赛事管理员只能指派本赛事已有 REVIEWER 授权者；禁止指派任务经办人本人或经办机构成员。跨角色冲突采用拒绝优先。
- 后端默认拒绝：全局 Guard 要求显式公共标记或权限动作。事务内重新加载当前会话、角色及指派，统一策略校验；读写和成功审计同事务，失败独立写审计，审计不可用则失败关闭。串行化冲突返回 409，不悄然覆盖。
- 本轮只提供本地 opaque bearer 会话：256 位随机令牌，仅存 SHA-256，8 小时过期，可注销。无密码登录、无微信交换接口；本地离线工具只在 dev 库创建合成引导管理员及会话，令牌写忽略目录、不打印。API 必须显式启用 local 身份模式且仅回环、非 production。默认关闭业务入口。生产身份接入须另做安全评审。
- 审计记录人员 ID、动作、资源 ID、时间、服务端 request ID 和结果，另存允许列表中的相关 UUID/角色/布尔值/策略动作 context，不存令牌、任意请求正文或材料。运行账号只能 INSERT/SELECT 审计，数据库触发器阻止 UPDATE/DELETE；这不是能防数据库 owner 篡改的外部不可抵赖日志。
- 授权探测接口只返回允许的权限锚点；content.write / review / file.download 仅是策略动作，不执行材料修改、审核或文件传输。真实文件及业务端点须在 CAAU-005 复用策略并补真实反例，不能以探测测试宣称 MVP-07/08 全通过。

不增加依赖。Context7 本轮查询 Nest/Prisma 文档网络失败；使用仓库固定版本及本地类型/实际生成与集成测试验证兼容性，不宣称已在线核验新版本。
