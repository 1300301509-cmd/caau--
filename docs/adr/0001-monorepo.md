# ADR-0001：采用单仓库与模块化单体

- 日期：2026-09-08
- 状态：本地组织方案已采用；技术栈与版本待工程初始化验证
- 来源：agent.md 第 2、8 节，以及本轮用户授权建立本地仓库管理基础

## 背景与决定

小程序、Web 后台共享业务接口，初期需要同步接口变更、数据模型与交付记录。采用 apps、packages、database、docs、deploy 的单仓库布局；后端按业务域组织一个模块化单体。现有原型保留在原路径，本轮未迁移或验证其实现。

## 替代方案与影响

多仓库便于独立权限管理，但初期会增加契约版本协调和工程配置成本；微服务还需要处理额外部署和跨服务一致性，当前没有明确需求支撑。

单仓库不意味着统一发布：小程序、Web、API 分别构建和发布。禁止跨应用源码导入；共享包按真实复用需求增加。未来若出现独立团队、发布或隔离要求，新增 ADR 评估拆分。
