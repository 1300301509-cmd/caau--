# ADR-0006：Web 配置复用、会话恢复与历史标签

CAAU-005 本地 Web 体验修复；基线 `89483a1`，分支 `codex/caau-005-web-polish`。依据演示记录的重复填写、入口过深、会话恢复繁琐、UUID/通用文件名问题。本轮不实现正式微信登录或真实模板下载。

- 配置复用仅复制用户有权读取的已发布要求到当前总部草案表单，生成新材料 ID；批量格式/大小/截止由总部显式填写并确认应用，不预置演示值。复用后必须保存、确认发布，不修改来源快照；模板版本标识与真实模板文件分别处理。
- 列表增加状态/下一步与直接办理/审核入口，详情将执行区域前置。保留现有创建、发布和只读要求查询。
- 会话只在内存。先验证新令牌的真实身份；同身份恢复不卸载编辑器、不清空输入、不自动执行写命令。重新读取权限/草稿/执行状态，对变化版本提示显式核对。不同身份确认切换后清除旧输入、选择与数据，不在 URL/Storage 中保存令牌或材料。重新加载整个浏览器仍不承诺恢复未保存内容。
- 历史 API 在已有资源鉴权事务内按 actorId 读取显示姓名，同时返回原稳定 ID；姓名是当前目录显示名，不冒充历史姓名快照，不改原作者、时间或历史记录。
- 追加第四次迁移，仅 FileUpload 新增可空 originalName，存储经处理的显示文件名，绝不作为存储路径。旧文件不伪造原名，回退到稳定 ID 与真实扩展名。上传意图接收可选原名以兼容旧客户端；去除路径、控制/双向字符、限制长度及危险文件名，扩展名由已校验文件类型确定。
- 文件信息与字节下载均重新验证当前任务/附件权限；下载使用安全 Content-Disposition（ASCII fallback + UTF-8 filename\*），不公开原始存储键或裸地址。显示姓名/原名不进入审计任意正文。

验收：真实浏览器 V1→退回→V2→通过→姓名/文件名/内容下载；配置批量和复用不改变来源；过期会话恢复保留输入并重新核对冲突/撤权；不同身份不显示旧输入；文件名路径/头注入/跨机构反例；追加迁移及旧数据/历史保留。复现、截图、结果统一记入 roadmap 和本地体验记录。
