# ADR-0032：单场改期的对话确认复用原票据

状态：CAAU-095 第一阶段本地实现；真实模型与微信运行时另行验收。

## 决策

- 只对单场改期开放文字确认。千问结构化路由可提出 `CONFIRM`，但只有当前授权会话的最新 `AgentTask` 处于 `PREVIEW_READY`、存在未过期的同任务票据时，服务端才进入原 `schedule.draft.adjust` 事务。模型不能指定票据 ID、命令 ID、赛事、场次或写入参数。普通问答和整套排程需求确认不走此分支；生产路由不靠原文业务关键词/正则决定意图。模拟解析器的固定表达仅用于回归。
- 文字确认额外绑定本轮路由前读取的 task ID/revision、会话 owner 和当前最新任务，执行时重新鉴权；票据仍绑定场次/参数哈希/赛程基线/时限。单场领域服务 CAS 写入 `DRAFT`，票据消费、不可变原命令回执及 USER/ASSISTANT 两条 turn 在**同一事务**提交。原按钮确认端点保留；流式接口只在最终 `result` 表示已提交。
- 条件重新定位时，在保存任务 revision 的同一事务取消旧待确认票据；显式新行动也取消同会话旧票据并使旧预览失效。普通插话不改任务。会话读取仍检查赛程版本和时限；响应丢失后只能按当前授权恢复原回执，不能重造命令。
- 沿用 `AgentTask`、`AgentConfirmationTicket`、`AgentCommandReceipt` 和生成客户端，无新业务表或迁移。小程序的当前对话卡展示确定性前后对比和回复提示；文字确认后重新读取会话及赛程，工作台返回时由既有 `useDidShow` 重新获取赛程。执行时版本与当前状态分开显示。

## 范围与取舍

第一阶段不开放文字确认整套候选、球队建档、附件上传或发布。模型路由与意图提取失败时不回退到生产正则或模拟结果。模拟模型/Node Taro 替身与隔离数据库证明业务安全，但不能证明千问、微信工具或真机。旧票据的按钮重放保留原领域幂等语义；文字确认失败/断流时须刷新会话查看原回执。
