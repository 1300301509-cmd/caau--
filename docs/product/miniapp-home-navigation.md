# 承办方小程序首页与导航规格

状态：CAAU-020 当前规格，2026-09-16。取代CAAU-019“首页直接放一个大材料提交入口”的布局；继续取代更早的“待办、赛事、我的”三项底部导航。材料办理业务规则不变。

## 进入顺序与信息架构

1. 无会话进入小程序时先打开本地测试身份页；选择后端提供的承办方测试身份后进入小程序主页。不默认选择任何承办方，也不实现正式微信登录。
2. 主页顶部是一张可替换的本地赛事主题占位图。图片不包含活动名称、日期、人数等虚构业务信息，不轮播。
3. 中部是紧凑业务板块网格，采用“图标在上、名称在下”的触控按钮。当前只展示“材料审批”，不渲染空位或虚构模块。
4. “材料审批”首次进入即默认选中。点击只更新主页选中状态，不跳页；选中项用克制的边框、浅底色和文字颜色共同标识。
5. 选中板块后，主页下方显示“材料提交”和“审核进度”两个子模块。后续真实板块应复用“板块选择 → 下方子模块”的结构，而不是恢复底部tabBar。
6. 当前测试身份和“切换测试身份”位于主页底部次要区域，不占用业务板块网格。

## 子模块

### 材料提交

复用现有赛事筛选、任务选择及办理详情：选择赛事 → 进入有权任务 → 新增或继续材料 → 保存草稿/上传附件 → 单份提交或退回后重交。截止、授权、幂等、冲突和不可变历史规则不变。

### 审核进度

按当前承办身份的既有任务权限读取单份材料快照，显示状态、版本、所属任务、最近实际操作人/时间及退回原因。点击记录进入现有详情查看操作与版本历史。

“审核进度”只是承办方查看总部处理结果，不提供开始审核、通过或退回按钮，不授予或暗示总部 `REVIEWER` 权限。

## 页面与返回

| 页面 | 路径 | 主要职责 | 返回方式 |
| --- | --- | --- | --- |
| 测试身份 | `/pages/profile/index` | 首次选择或后续切换本地承办身份；手动令牌为折叠次入口 | 选择成功自动进入主页；已有身份可返回主页 |
| 主页 | `/pages/home/index` | 横幅、业务板块网格、当前板块的子模块及次要身份入口 | 小程序根页；默认恢复“材料审批”选中状态 |
| 材料提交 | `/pages/materials/index` | 自动核权、赛事筛选、任务列表和办理入口 | 明确“返回首页” |
| 审核进度 | `/pages/progress/index` | 赛事筛选、承办方材料状态、退回原因及历史入口 | 明确“返回首页” |
| 任务详情 | `/pages/task/index?id=…` | 保留新版单份及旧整包办理、附件、提交和历史 | 明确“返回首页”；有未保存输入/未知命令先确认 |
| 工程检查 | `/pages/index/index` | 隐藏的本地连接辅助页 | 使用平台返回 |

不配置 `tabBar`，不恢复旧 `/pages/todo/index`、`/pages/events/index` 页面。

## 状态与保护

- 无会话：主页自动转到测试身份选择；材料提交、审核进度和任务深链不显示受保护内容。
- 加载中：显示正在读取赛事和任务，不以空白代替。
- 无赛事/无任务/无材料记录：分别显示明确空状态，不生成占位业务数据。
- 加载失败：显示现有安全错误文案，保留“立即核对”或“重新加载任务”；401清理会话与受保护内容，403清理越权范围。
- 列表切后台停止轮询、回前台立即核对；详情继续沿用约2秒同步、请求代次和身份隔离。
- 新版详情沿用协调器本地编辑缓冲、冲突核对和 `enableAlertBeforeUnload`；显式返回首页也先检查dirty/pending。旧整包详情同样检查编辑器dirty/pending。取消离开时必须保留当前输入。

## 当前视觉边界

本轮只确认主页和两个子模块入口。内部赛事筛选、任务卡片、进度列表和详情继续使用现有样式；待主页视觉确认后再单独统一，不把本轮截图冒充全小程序视觉完成。

横幅与板块图标均为仓库本地可替换资源，不含远程请求。后端角色、赛事/任务授权、截止、交接和关闭规则不变；本轮不新增API、数据库字段、正式微信登录或承办方默认身份。
