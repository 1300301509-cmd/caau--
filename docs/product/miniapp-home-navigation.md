# 承办方小程序首页与导航规格

状态：CAAU-026 当前规格，2026-09-16。CAAU-025固定赛事选择窗不变，右侧用户Logo缩小为正方形并保持原图比例；继续沿用双列顶栏和CAAU-020板块式主页，并取代CAAU-019“大材料提交入口”和更早的“待办、赛事、我的”三项底部导航。材料办理业务规则不变。

## 进入顺序与信息架构

1. 无会话进入小程序时先打开本地测试身份页；选择后端提供的承办方测试身份后进入小程序主页。不默认选择任何承办方，也不实现正式微信登录。
2. 主页内容顶部为双列区域：左侧紧凑赛事状态栏，右侧在较小正方形容器内以`aspectFit`等比展示用户提供并纳入本地资源的CAAU Logo，不拉伸或裁切；其下才是可替换的本地赛事主题占位图。赛事栏只显示赛事名称和CSS方向箭头，不显示“当前赛事”、任务数或“切换”文字；整条仍满足移动端触控尺寸。
3. 点击赛事栏后保持主页各元素坐标不变，使用全页半透明暗色遮罩和固定520px设计高度的居中选择窗口。窗口包含标题、明确关闭按钮和固定424px设计高度的纵向`ScrollView`；赛事再多也只在窗口内部上下滚动，不继续扩大窗口或页面。点击遮罩、关闭按钮或选择赛事均关闭窗口。
4. 选择窗口只显示赛事名称；数据只使用后端按当前承办身份返回的赛事，不拼接或缓存其他身份的数据。当前项以浅底色和“当前”文字共同标识，不只依赖颜色。首次读取优先恢复当前会话仍有权的赛事，否则选择后端返回的第一项；切换身份时清空赛事上下文。无赛事、读取中和读取失败有明确状态，读取失败时点击状态栏重试。
5. 中部是紧凑业务板块网格，采用“图标在上、名称在下”的触控按钮。当前只展示“材料审批”，不渲染空位或虚构模块。
6. “材料审批”首次进入即默认选中。点击只更新主页选中状态，不跳页；选中项用克制的边框、浅底色和文字颜色共同标识。
7. 选中板块后，主页下方显示“材料提交”和“审核进度”两个子模块。入口携带当前赛事ID，子页重新用授权赛事列表校验，不把客户端选择当权限；没有赛事时入口禁用。后续真实板块应复用“板块选择 → 下方子模块”的结构，而不是恢复底部tabBar。
8. 当前测试身份和“切换测试身份”位于主页底部次要区域，不占用业务板块网格。

## 子模块

### 材料提交

复用现有任务选择及办理详情：主页选择赛事 → 进入该赛事有权任务 → 新增或继续材料 → 保存草稿/上传附件 → 单份提交或退回后重交。子页显示当前赛事及“返回首页切换”提示，不再重复铺开赛事按钮。截止、授权、幂等、冲突和不可变历史规则不变。

### 审核进度

按当前承办身份的既有任务权限读取单份材料快照，显示状态、版本、所属任务、最近实际操作人/时间及退回原因。点击记录进入现有详情查看操作与版本历史。

“审核进度”只是承办方查看总部处理结果，不提供开始审核、通过或退回按钮，不授予或暗示总部 `REVIEWER` 权限。

## 页面与返回

| 页面 | 路径 | 主要职责 | 返回方式 |
| --- | --- | --- | --- |
| 测试身份 | `/pages/profile/index` | 首次选择或后续切换本地承办身份；手动令牌为折叠次入口 | 选择成功自动进入主页；已有身份可返回主页 |
| 主页 | `/pages/home/index` | 当前授权赛事状态/切换、横幅、业务板块、子模块及次要身份入口 | 小程序根页；默认恢复“材料审批”选中状态 |
| 材料提交 | `/pages/materials/index?event=…` | 重新核权、当前赛事任务列表和办理入口 | 明确“返回首页”；赛事切换统一回首页 |
| 审核进度 | `/pages/progress/index?event=…` | 当前赛事的承办方材料状态、退回原因及历史入口 | 明确“返回首页”；赛事切换统一回首页 |
| 任务详情 | `/pages/task/index?id=…` | 保留新版单份及旧整包办理、附件、提交和历史 | 明确“返回首页”；有未保存输入/未知命令先确认 |
| 工程检查 | `/pages/index/index` | 隐藏的本地连接辅助页 | 使用平台返回 |

不配置 `tabBar`，不恢复旧 `/pages/todo/index`、`/pages/events/index` 页面。

## 状态与保护

- 无会话：主页自动转到测试身份选择；切换身份清空已选赛事，材料提交、审核进度和任务深链不显示受保护内容。
- 加载中：主页状态栏与子页显示正在读取赛事和任务，不以空白代替；传入赛事不在后端授权列表时只回落到当前仍有权赛事。
- 无赛事/无任务/无材料记录：分别显示明确空状态，不生成占位业务数据。
- 加载失败：显示现有安全错误文案，保留“立即核对”或“重新加载任务”；401清理会话与受保护内容，403清理越权范围。
- 列表切后台停止轮询、回前台立即核对；详情继续沿用约2秒同步、请求代次和身份隔离。
- 新版详情沿用协调器本地编辑缓冲、冲突核对和 `enableAlertBeforeUnload`；显式返回首页也先检查dirty/pending。旧整包详情同样检查编辑器dirty/pending。取消离开时必须保留当前输入。

## 当前视觉边界

本轮只确认主页和两个子模块入口。内部赛事筛选、任务卡片、进度列表和详情继续使用现有样式；待主页视觉确认后再单独统一，不把本轮截图冒充全小程序视觉完成。

横幅与板块图标均为仓库本地可替换资源，不含远程请求。后端角色、赛事/任务授权、截止、交接和关闭规则不变；本轮不新增API、数据库字段、正式微信登录或承办方默认身份。
