# 承办方小程序首页与导航规格

状态：CAAU-031登录入口更新，2026-09-18。采用用户最新参考图与总部Web一致的暖白、杏色、深绿品牌语言；此前“测试身份页作为首屏”的方案不再作为正式产品入口。

## 进入顺序与信息架构

1. 无会话进入小程序时先打开独立登录页；页面提供微信快捷登录主动作、协议确认、权限归属说明和明确状态反馈。当前尚无正式微信code交换接口，点击主动作不会创建或模拟会话；仅开发版显示“本地联调入口（非微信登录）”，由此进入既有测试身份页。已有内存会话进入登录页时返回主页。
2. 顶部为问候区及右侧等比Logo，下方独立一行紧凑赛事选择。移除占位横幅，突出真实业务入口；赛事栏保持名称和方向箭头，不显示虚构任务数。
3. 点击赛事栏后保持主页各元素坐标不变，使用全页半透明暗色遮罩和固定520px设计高度的居中选择窗口。窗口包含标题、明确关闭按钮和固定424px设计高度的纵向`ScrollView`；赛事再多也只在窗口内部上下滚动，不继续扩大窗口或页面。点击遮罩、关闭按钮或选择赛事均关闭窗口。
4. 选择窗口只显示赛事名称；数据只使用后端按当前承办身份返回的赛事，不拼接或缓存其他身份的数据。当前项以浅底色和“当前”文字共同标识，不只依赖颜色。首次读取优先恢复当前会话仍有权的赛事，否则选择后端返回的第一项；切换身份时清空赛事上下文。无赛事、读取中和读取失败有明确状态，读取失败时点击状态栏重试。
5. “我的工作台”采用两列圆角卡片：杏色材料审批、薄荷绿承办申请，包含图标、标题、简短说明及选中提示；下方办理入口采用纵向白色卡片。
6. “材料审批”首次进入默认选中；两个板块点击都只更新主页选中状态，不立即跳页，选中项使用边框、浅底和文字共同标识。
7. 选中“材料审批”后显示“材料提交”和“审核进度”，入口携带当前赛事ID并重新核权，无赛事时禁用。选中“承办申请”后显示“申请办理”，不携带或检查赛事ID；只要后端身份响应返回有效申请办理机构，即使赛事列表为空也可进入并新建申请。后续真实板块继续复用“板块选择→下方子模块”，底部提供“首页”和“我的”两个原生tabBar入口。
8. 当前测试身份和“切换测试身份”位于主页底部次要区域，不占用业务板块网格。

## 子模块

### 赛事承办申请

进入独立申请列表、草稿表单、附件、提交/补充、版本差异、历史及获批赛事基本信息；范围来自独立申请办理grant，不依赖主页赛事。申请获批不自动创建材料任务，赛事基本查看权也不让“材料提交”入口出现未指派任务。详细交互见[申请小程序手册](../runbooks/event-hosting-application-miniapp.md)。

### 材料提交

复用现有任务选择及办理详情：主页选择赛事 → 进入该赛事有权任务 → 新增或继续材料 → 保存草稿/上传附件 → 单份提交或退回后重交。子页显示当前赛事及“返回首页切换”提示，不再重复铺开赛事按钮。截止、授权、幂等、冲突和不可变历史规则不变。

### 审核进度

按当前承办身份的既有任务权限读取单份材料快照，显示状态、版本、所属任务、最近实际操作人/时间及退回原因。点击记录进入现有详情查看操作与版本历史。

“审核进度”只是承办方查看总部处理结果，不提供开始审核、通过或退回按钮，不授予或暗示总部 `REVIEWER` 权限。

## 页面与返回

| 页面 | 路径 | 主要职责 | 返回方式 |
| --- | --- | --- | --- |
| 登录 | `/pages/login/index` | 无会话首屏；微信快捷登录视觉入口、协议确认和登录状态反馈 | 登录成功后应进入主页；当前正式微信交换未接入，不伪造成功 |
| 测试身份 | `/pages/profile/index` | 仅开发联调或后续切换本地承办身份；手动令牌为折叠次入口 | 选择成功自动进入主页；发布版登录页不展示此入口 |
| 主页 | `/pages/home/index` | 当前授权赛事状态/切换、材料审批/承办申请板块、子模块及次要身份入口 | 已登录默认首页；无会话或401统一回登录页 |
| 承办申请 | `/pages/hosting/index` | 独立申请列表、表单、附件、提交/补充、版本差异/历史和获批入口 | 明确“返回首页”；不依赖赛事选择 |
| 获批赛事 | `/pages/event-info/index?id=…` | 以独立基本信息查看权显示正式赛事只读资料 | 返回申请；不显示编辑/审核/任务入口 |
| 材料提交 | `/pages/materials/index?event=…` | 重新核权、当前赛事任务列表和办理入口 | 明确“返回首页”；赛事切换统一回首页 |
| 审核进度 | `/pages/progress/index?event=…` | 当前赛事的承办方材料状态、退回原因及历史入口 | 明确“返回首页”；赛事切换统一回首页 |
| 任务详情 | `/pages/task/index?id=…` | 保留新版单份及旧整包办理、附件、提交和历史 | 明确“返回首页”；有未保存输入/未知命令先确认 |
| 工程检查 | `/pages/index/index` | 隐藏的本地连接辅助页 | 使用平台返回 |

配置“首页”“我的”两个原生 `tabBar` 入口，不恢复旧 `/pages/todo/index`、`/pages/events/index` 页面。

## 状态与保护

- 无会话：主页、承办申请、赛事和任务深链统一回登录页，不显示受保护内容；本地切换身份仍清空已选赛事。
- 加载中：主页状态栏与子页显示正在读取赛事和任务，不以空白代替；传入赛事不在后端授权列表时只回落到当前仍有权赛事。
- 无赛事/无任务/无材料记录：分别显示明确空状态，不生成占位业务数据。
- 加载失败：显示现有安全错误文案，保留“立即核对”或“重新加载任务”；401清理会话与受保护内容，403清理越权范围。
- 列表切后台停止轮询、回前台立即核对；详情继续沿用约2秒同步、请求代次和身份隔离。
- 新版详情沿用协调器本地编辑缓冲、冲突核对和 `enableAlertBeforeUnload`；显式返回首页也先检查dirty/pending。旧整包详情同样检查编辑器dirty/pending。取消离开时必须保留当前输入。

## 当前视觉边界

登录页使用本地CAAU Logo、暖白背景、杏色场景标签、深绿主动作和白色底部登录卡；触控目标不小于44px，375px模拟器无横向溢出。主页、材料两个入口和承办申请入口沿用同一浅色卡片、蓝色选中态及触控尺寸；承办申请内部表单/列表延续现有样式并已在官方模拟器实际显示。开发者工具页面截图不代表文件平台闭环、动态字体、辅助技术、深色模式或真机验收完成。

Logo与板块图标均为仓库本地资源，不含远程请求。后端角色、赛事/任务授权、截止、交接和关闭规则不变；登录页本轮不新增API、数据库字段、正式微信登录或承办方默认身份。服务协议和隐私政策正文、微信AppID/code交换及绑定规则仍待正式接入。

## 底部导航补充（2026-09-18）

用户要求预留“首页”“我的”。使用微信原生tabBar，暖白背景、深绿色选中态，分别连接首页和现有个人/测试身份页；业务详情保持二级页面，不增加虚构个人功能。跳转个人页统一使用switchTab，避免普通导航无法进入tab页。
