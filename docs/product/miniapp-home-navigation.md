# 承办方小程序首页与导航规格

状态：CAAU-019 当前规格，2026-09-16。取代旧“待办、赛事、我的”三项底部导航，但不改变材料办理业务规则。

## 信息架构

1. 小程序首屏为“材料提交”，只显示一个同名主业务入口，不展示其他业务模块、标签占位、统计图表或演示数据。
2. 点击“进入材料提交”进入统一流程：选择赛事 → 查看该范围任务 → 进入任务 → 新增或继续材料 → 保存/上传/提交 → 查看审核进度和版本历史。
3. 赛事是流程内筛选，任务是办理对象；不再分别占用“赛事”和“待办”顶层标签。
4. 本地测试身份位于首页次要文字入口。身份页只在后端明确启用本地测试模式时列出可选承办方，不默认选择某一家；同时保留折叠的手动短期令牌入口。它不是正式微信登录。
5. 工程连接检查只从身份页的次要入口访问，不属于首页业务板块。

## 页面与返回

| 页面     | 路径                     | 主要职责                                         | 返回方式                                    |
| -------- | ------------------------ | ------------------------------------------------ | ------------------------------------------- |
| 首页     | `/pages/home/index`      | 单一“材料提交”入口；显示当前测试身份或未载入状态 | 小程序根页                                  |
| 材料提交 | `/pages/materials/index` | 自动核权、赛事筛选、任务列表、材料状态与审核进度 | 明确“返回首页”                              |
| 任务详情 | `/pages/task/index?id=…` | 保留新版单份及旧整包办理、附件、提交和历史       | 明确“返回首页”；有未保存输入/未知命令先确认 |
| 测试身份 | `/pages/profile/index`   | 选择本地承办身份、手动测试令牌、退出             | 返回首页；载入后进入材料提交                |
| 工程检查 | `/pages/index/index`     | 隐藏的本地连接辅助页                             | 使用平台返回                                |

不配置 `tabBar`，不保留空的多标签导航，也不保留旧 `/pages/todo/index`、`/pages/events/index` 页面。

## 状态与保护

- 无会话：材料提交和任务深链不显示受保护内容，提供“载入本地测试身份”和返回首页。
- 加载中：显示正在读取赛事和任务，不以空白代替。
- 无赛事/无任务：分别显示明确空状态，不生成占位赛事或统计值。
- 加载失败：显示现有安全错误文案，保留“立即核对”或“重新加载任务”；401 清理会话与受保护内容，403 清理越权范围。
- 列表切后台停止轮询、回前台立即核对；详情继续沿用约2秒同步、请求代次和身份隔离。
- 新版详情沿用协调器本地编辑缓冲、冲突核对和 `enableAlertBeforeUnload`；显式返回首页也先检查 dirty/pending。旧整包详情同样检查编辑器 dirty/pending。取消离开时必须保留当前输入。

## 保持不变

草稿CAS、私有附件上传/确认/绑定/下载、单份幂等提交、退回修改、V2重交、共享审核进度、不可变版本和历史均复用现有组件与API。后端角色、赛事/任务授权、截止、交接和关闭规则不变；本轮不新增API、数据库字段、正式微信登录或承办方默认身份。
