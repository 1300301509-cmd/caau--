# 资料审核 Web 前端布局

状态：CAAU-014 修订方案，2026-09-15。用户否定原 12 板块首页方案，指定参考 [Tabler](https://github.com/tabler/tabler) 的紧凑、专业、高信息密度风格，并要求当前前端只呈现资料审核一个业务模块。

## 当前范围

- 唯一可见业务导航：资料审核。
- 根地址 `/` 与标准地址 `/materials` 均进入资料审核；刷新、查询参数深链和当前导航高亮保持有效。
- 页面复用现有 `IndividualPage`、`IndividualWorkspace` 和 `@caau/api-client`，保留承办方单份材料新增/提交、总部共享审核、不可变版本与历史、附件和自动同步，不复制业务实现。
- 本地测试身份入口继续保留并明确标识；导航不授予身份或权限，所有读写继续由后端校验。
- `/workspace` 不出现在产品导航；现阶段仅为既有自动化回归保留隐藏兼容入口，不作为当前前端模块交付。
- `/system/health` 仅为工程测试辅助地址，不属于产品导航。

## 视觉方向

仅移植 Tabler 的视觉语言，不引入 Bootstrap，也不替换现有 React 19、Vite 8 和 Ant Design 6：

- 白色窄侧栏、浅灰页面底、细边框、弱阴影、4～5px 小圆角。
- 蓝色只用于当前导航、主要操作和选中状态；不使用大面积深色侧栏或装饰性渐变。
- 顶部栏 56px，页面标题区紧凑；内容以列表、筛选、详情和操作为核心，不增加经营指标卡片。
- 桌面侧栏可折叠，低于 992px 使用遮罩式导航；375px 不产生横向页面滚动。
- 使用现有状态文字、标签和服务端数据，不添加虚构数量、金额或完成率。

## 权限与业务边界

本轮不修改数据库模型、API、状态机、角色或赛事授权。资料审核页面仍根据导入的本地会话显示承办办理或总部审核能力；无会话、会话失效、撤权和跨机构访问继续由现有前后端保护处理。正式登录、注册、密码找回和账号中心不在本轮范围。
