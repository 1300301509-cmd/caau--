# CAAU-053 我的比赛移动工作台

## 范围与结构

用户要求重新设计承办方小程序“我的比赛”的界面及模块组织。沿用五个业务子模块和真实 API，不改变权限、赛事状态、球队快照、赛程发布或单场安排规则。

结构：我的比赛 → 当前赛事与切换 → 球队/场次数/工作人员概览 → 五个业务入口 → 赛程冲突与物料准备提醒 → 近期赛程。统计仅使用当前赛事已授权响应，不将加载失败显示为零；候选赛程明确标为未发布。页面每次重新显示刷新数据，不展示技术性自动同步栏。

- 球队管理：本赛事球队、球队档案、从档案添加；编辑表单分为基本资料、所在地区、补充信息。
- 赛程编排：保留按周翻页，新增周一至周日日期选择及每日场次；再次点击选中日恢复全周。待安排场次不因日期过滤消失。
- 物料管理：清单、准备状态、照片和历史；沿用现有写入与上传恢复。
- 赛事情况：场次与参赛名单；工作人员仍走人员管理。
- 人员管理：赛事工作人员名单、单场安排与历史。

工作台切换赛事使用路由替换，避免积累页面栈；子模块仍继承路由中的赛事 ID。编辑页保留离开确认、请求幂等和并发冲突输入保护。

## 视觉决策

采用浅灰工作区、白色内容面、CAAU 深绿赛事识别区。绿色只突出当前赛事与主要动作，警告使用独立琥珀色。五个模块使用本地统一线条 SVG，去掉无业务意义的编号；不引入远程图片、字体或组件库依赖。

核心色：正文 #172D29、辅助文字 #596B65、主色 #195E50、背景 #F3F6F7、内容面 #FFFFFF、警告背景 #FFF7E8。中文使用系统/PingFang 字体；标题、内容和注释分级。Taro 源 CSS 使用工程既有 px 转 rpx 规则，按钮最小高度88，底部保留安全区。

设计检索首次返回偏体育营销页，第二次返回简约运营界面。只采纳功能层级、对比度、触控和布局建议，不引入营销页大字、外部字体及 GSAP。
