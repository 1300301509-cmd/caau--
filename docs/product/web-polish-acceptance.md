# CAAU-005 本地 Web 体验修复与验收

范围：基线 `89483a1`，分支 `codex/caau-005-web-polish`；仅本地 Web 体验、必要 API 元数据和追加迁移。决策见 [ADR-0006](../adr/0006-web-recovery-and-file-labels.md)。本轮不扩展真实模板管理，不实现正式微信登录。

## 四项复现与修复

| 问题 | 本轮复现 | 修复及验收 |
| --- | --- | --- |
| 配置重复 | 用旧构建及原演示 API 确认五套模板版本、大小、格式、截止重复填写 | 公共字段先填再确认应用；授权可见的已发布配置可预览、确认复用。只进入新草案表单，材料 ID 重建，必须保存及总部确认发布；不复制附件、指派、提交和审核，不改来源快照。无演示默认值成为业务规则。 |
| 入口过深 | 原承办区域位于五项只读要求之后 | 增加跨赛事待办和列表直接办理/审核按钮，显示执行状态及下一步；执行区域前置并定位焦点。办理状态变化刷新列表，详情仍重新鉴权。 |
| 会话恢复 | 通过注销专属测试会话制造真实 401，同一身份重新导入后旧版配置编辑器消失 | 先验证新令牌真实身份。同身份保留输入、确认上传 ID、未确认提交命令和审核意见，重读权限与版本；变化修订必须显式核对，不自动保存、提交或重审。不同身份确认后清空本页旧状态及非受控表单；异步旧响应不得重新带回旧选择，切换前发起的附件下载不得在新身份下落地。 |
| 历史与文件名 | 原历史只有 UUID，下载建议文件名为 `.bin` | 当前目录显示名与稳定作者 ID 同时显示；历史作者、时间、内容不修改。新上传记录安全原文件名，文件信息及字节下载均鉴权；浏览器使用正确扩展名及 UTF-8 文件名，存储始终为服务器 UUID。 |

配置复用不是模板文件管理。源配置中的截止与模板版本需要总部重新核对，系统不偷偷延期；未确认来源不会发送配置写请求。已发布任务的要求快照不因复用或执行状态变化而改变。

## 数据与安全边界

- 新增 `202609090001_file_labels`：仅 `FileUpload.originalName` 可空列。暂存检查发现 Prisma 生成 SQL 的末尾空行；为保留已部署字节/checksum，`.gitattributes` 仅对正式迁移允许末尾空行，其他空白检查保持开启，再运行常规 `git diff --check`。旧三次迁移逐字节保留；升级测试包含第三次迁移上的旧文件行，第四次迁移后所有原字段不变。
- dev 实际从 3 次迁移升级到 4 次，status 正常；前后只读摘要验证 21 张业务表的全部旧行与 6 个私有对象不变，旧迁移 checksum 不变。快照比较仅排除新增字段，未 reset、删卷或改写旧提交。升级前的浏览器复现另新增一个明确标注“不发布”的合成草案，未动原已通过演示任务。
- 去除文件名路径、控制/双向字符及危险字符，限制长度，扩展名由校验过的类型决定。保留 attachment/octet-stream、no-store、nosniff；不公开 storageKey、不将原名作路径。不是病毒扫描或完整文件语义验证。
- 旧文件原名未曾记录，不伪造或根据演示目录反向写库；显示“旧附件原名未记录”，回退到稳定 ID 与真实扩展名。旧演示附件因而不会恢复成曾经的本机文件名。
- 会话仅留内存；同身份保留仅限本页，不承诺关闭或整页刷新后恢复。切换身份不撤销已发送的业务请求，须切回原身份核对结果。微信会话、原生文件 API 与真机行为未验收。
