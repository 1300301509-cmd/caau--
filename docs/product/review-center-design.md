# CAAU-028 总部赛事审核中心设计

状态：第一版前端实现，待用户视觉反馈。依据2026-09-17用户提供的总部后台参考图和“现阶段只需要赛事审核中心”的范围。

## 视觉与信息结构

- 以浅杏色外底、白色侧栏、奶油白内容区和圆角卡片还原参考图的柔和观感；杏色用于导航，青绿色用于操作，浅杏/薄荷/雾蓝分别区分审核概况。
- 主导航只有“赛事审核中心”。默认根地址进入承办申请审核；办赛材料审核作为同模块的第二入口，保留既有权限和办理流程。这是本版的信息组织选择，不代表新增业务规则。
- 承办申请主区依次为三张真实状态统计卡、赛事/机构搜索、六种筛选、申请列表和分页。右侧展示当前可见申请的结论进度与最近三次提交。
- 点申请进入详情弹层，集中显示当前提交、私有附件、不可变历史版本、相邻版本差异及审核操作。弹层内容独立滚动，标题、关闭按钮保留可达。
- 登录后的测试身份入口移至右上角；未登录展示身份选择和明确空态，不填假数。原有赛事获批结果仍可打开赛事详情，但不再增加主导航模块。

## 数据与交互边界

概况仅统计当前后端授权可见的已提交申请；“已形成审核结论”按已通过加已驳回占比计算，待补充不算完成。搜索、筛选、排序、每页六项均在已授权读取的数据上进行，不扩大权限。加载失败、无身份、无权、空搜索结果和零申请分别保留可理解反馈。

现有开始审核、补充、驳回、通过、CAS/幂等、受控下载和会话接口继续使用生成客户端。前端增加历史版本快照的可展开呈现，原来的无目标锚点被实际内容替代。无新后端、迁移、外部依赖、通知或业务写入自动化。

## 隔离预览

独立分支：`codex/caau-028-review-center`；基线：`8d46137`。工作树位于主仓库的`.local/worktrees/caau-028-review-center`，主工作区的其他在途修改保留。

预览地址：<http://127.0.0.1:5175/>。前端通过Vite开发代理`/api-backend`读取既有回环API，避免为独立预览修改后端CORS。该代理仅用于开发服务。

进入方式：选择“总部审核员甲”，点击“进入”。现有五项申请明确标注“合成演示”；预览未创建或修改它们。切换“承办方B”会显示无审核权限。

运行预览：先按本地工具文档启用Node24.20.0/pnpm10.32.1，在本工作树运行：

```sh
VITE_API_BASE_URL=/api-backend corepack pnpm --filter @caau/admin exec vite --host 127.0.0.1 --port 5175 --strictPort
```
