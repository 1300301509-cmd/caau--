# CAAU-033 办赛必填材料重构

状态：用户已确认流程，2026-09-18。承办申请获批后填写，七项作为整套提交，总部统一通过或退回补充。

## 已确认范围

- 承办方：【我要办赛】→【办赛材料】。
- 总部：【赛事审核中心】→【办赛材料审核】。
- 双端继续沿用现有暖白、杏色、绿色视觉；材料真实保存、提交并由总部审核。

| 必填内容 | 页面控件 | 用户说明 |
| --- | --- | --- |
| 营业执照 | 私有附件上传与预览 | 必须提交 |
| 办赛公司/机构简介 | 多行文本 | 3～4句话，介绍所在地点、办赛经验等 |
| 比赛场地照片 | 多图上传与预览 | 必须提交 |
| 公司银行账户信息 | 结构化表单 | 必须填写；拆分户名、开户银行、银行账号三个输入 |
| 报名开始时间与截止时间 | 两个日期时间选择器 | 两端均必填 |
| 比赛日期 | 日期选择 | 必填；沿用比赛开始/结束日期，单日赛事两端选择同一天 |
| 报名联系人手机号 | 手机号输入 | 必填 |

## 页面方案

承办方在现有草稿表单内填写赛事日期、机构简介、收款账户和报名信息，在附件区上传执照与场地照片；显示必填标识、缺失字段提示与审核状态。支持未填完保存草稿，正式提交时前后端同时校验必填内容；失败不丢失输入。附件使用已有私有文件授权机制，银行账号与手机号不出现在列表摘要和日志中。

总部列表展示赛事、承办机构、提交时间与审核状态；详情按相同分组阅读文本、日期及私有附件，并呈现提交者、审核者、审核意见和版本历史。整套开始审核、通过或退回补充，历史内容保持不可变。

当前技术校验：报名截止不得早于开始时间；至少存在已确认上传的营业执照及场地照片；手机号、账号去除首尾空白并按最终格式规则校验。简介显示3～4句话的填写提示，不直接以标点数机械判断句数。报名截止与比赛日期之间的业务关系尚未确认，不自行强制加入。

## 用户确认的流程

1. 整套提交、统一审核。本次新办赛材料不再逐项审批，旧单份材料保留历史入口与权限。
2. 承办申请获批后填写；一场已获批赛事对应一套材料，草稿/待补充可修改，提交生成不可变版本，审核通过后冻结。通过材料不再次创建赛事，不自动修改已有赛事资料。
3. 本机构具有有效承办申请经办授权的人员协作办理，总部沿用已有审核授权及超级管理员能力；服务端逐请求鉴权，跨机构不可读写，提交人不能自审。
4. 建立草稿由承办方点击“进入办赛材料”触发，若已存在则返回同一套材料，不自动新增旧任务。草稿不要求填完，正式提交必须齐全。手机号使用11位大陆手机号，银行账号按数字字符串保存（不转数值，保留前导零）。

## 实施验收

- 缺少任一必填内容时服务端拒绝正式提交，前端列明缺失字段；草稿可部分保存。
- 授权承办方提交后，总部对应审核入口能读到同一版本；审核结果及意见在承办方可见。
- 补充/重交、历史、重复提交、并发编辑、机构隔离、附件及敏感字段权限按确认后的流程验证。
- 数据变更以隔离数据库验证；Web、微信开发者工具、真实微信登录及真机分别记录证据。
