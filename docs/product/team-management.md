# 球队管理（CAAU-041）

## 已确认边界

球队可以先由承办方手工登记，后续再绑定小程序账号。球队名称、负责人、联系方式、所在城市等资料需要持久保存。小程序球队档案与比赛球队资料分开；比赛中的信息属于该比赛，不随小程序资料变化自动更新。

## 本期功能

Web【比赛管理中心 → 球队管理】提供两个页签：

- **球队档案**：录入、搜索、编辑、归档球队，显示是否已绑定账号。
- **本赛事球队**：新录入并加入当前赛事，或从已有档案添加；独立编辑比赛内资料，并通过二次确认移出当前赛事。默认只显示参赛中，可筛选已退出历史。

必填：球队名称、负责人、联系方式、省份、城市。选填：简称、区县、地址、所属机构/俱乐部、简介、备注。上述可选字段为本期实施选择，不是用户已逐项确认的规则。电话支持数字、国际前缀、空格及分隔符；名称和手机号均不作为唯一身份。同名提示仅供核对，不自动合并。

球队加入赛事时复制当前资料，并记录来源球队 ID 和来源版本。此后两边都可独立变更；重复添加返回原赛事记录，不刷新资料。档案归档不让已参加的赛事自动退出；某场赛事退出不影响主档案或其他赛事。不提供物理删除及自动合并。移出确认显示球队名、赛事名和历史保留边界；若球队已进入赛程，先提示退出会使当前赛程产生球队不可用冲突，但不删除或改写候选/已发布赛程及历史。已退出球队不能进入新编排；既有恢复参赛能力不变。

## 权限

- 总部超级管理员可管理全范围。
- 有效承办方/赛事经理组织成员可登记和读取本机构档案；未绑定档案由该机构维护。
- 球队绑定有效账号关系后，仅该球队的有效账号关系或总部超级管理员可改主档案；原录入机构仍可查看自己的记录。
- 赛事资料由该赛事有效经理授权，或该赛事有效承办机构中持有有效申请办理授权的承办人员管理。
- 基本信息查看授权、材料任务授权、审核员和系统管理员身份本身不授予赛事球队写权。
- 球队账号关系只赋予其球队主档案权限，不赋予比赛资料修改权。

每次请求由后端校验当前会话及授权。前端按钮不是权限边界。资料修改携带版本号，过期版本返回 409，不自动覆盖；新增记录使用客户端 UUID 和规范化请求摘要保证重试幂等。修改与不可变版本、审计在同一事务内完成。

## 账号后续接入

本期建立 `TeamMembership` 数据关系与读取/编辑权限支持，**没有开放账号绑定写接口、邀请认领页面或小程序球队资料页面**。后续认领应采用授权邀请、登录确认、审批/确认后绑定已有球队 ID；不按手机号或名字自动认领，不把球队账号赋成承办方角色。微信登录关联与球队认领是两个独立过程。

当前接口可以供后续小程序通过同一生成客户端使用；比赛资料仍独立保存。已存在账号与待认领档案重复时，必须经过人工核对，不自动迁移或合并历史比赛。

## 验收边界

真实数据库验证需覆盖无账号登记、机构隔离、赛事授权撤销、双向快照隔离、两场比赛隔离、重复添加、并发修订、归档/退出及历史禁止改删。浏览器验收应使用隔离库真实 API，不写入本机已有办赛数据。微信平台、真机及邀请认领属于后续验收。
