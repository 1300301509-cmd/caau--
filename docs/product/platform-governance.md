# 平台治理产品范围与验收

用户确认的完整范围见 [计划](../planning/caau-governance.md)。本说明区分已接入的模块与未来模块；任务状态和实测证据统一在 [roadmap](../planning/roadmap.md)。

## 权限矩阵

| 身份 | 治理总览/审计/会话/用量/对话 | 原账号管理 | 业务资源 |
| --- | --- | --- | --- |
| 总部超级管理员 | 每次鉴权允许，正文需原因 | 原受控流程 | 使用现有策略 |
| 系统管理员 | 拒绝 | 沿用原 canManageAccounts 判定 | 不因系统管理角色获得赛事内容 |
| 赛事管理员 | 拒绝 | 原策略 | 赛事授权范围 |
| 审核员 | 拒绝 | 原策略 | 已分配审核、禁止内容修改及自审 |
| 承办方经办人 | 拒绝 | 原策略 | 自己有效分配，禁止跨机构 |
| 停用/过期/撤销/伪造身份 | 拒绝 | 拒绝 | 拒绝 |

权限说明使用服务端实际函数，不维护平行授权表。账号全景展示组织、角色、停用、赛事授权、经办审核来源；具体操作继续在执行时检查资源状态。业务读取或下载权不会由治理入口自动授予。

## 业务盘点与事件目录

以下是现有源码的接入范围；已有业务历史表继续保存完整版本，统一审计只放允许字段与版本/资源引用。

| 模块 | 事件前缀/证据 | 状态与边界 |
| --- | --- | --- |
| 身份、登录、账号授权 | authentication/session/admin/workspace，AuditRecord | 已有身份模块，治理增加会话撤销、来源解释；历史未分类不回填原因 |
| 办赛申请及发布 | hosting、events，HostingApplicationAction/Submission/Command | 已有真实业务；审核等待以提交时间计算，不虚构期限 |
| 整包材料与模板 | material/task/file/template，SubmissionVersion/Command/AssignmentHistory | 复用原授权事务；文件正文继续走原下载接口 |

| 赛事人员与情况 | eventStaff/eventSituation，历史版本 | 已有，授权以赛事范围为准 |

当前统一审计来自后端授权事务，各终端共用。需以对应API真实请求验证关键动作，不能仅凭装饰器数量声称全覆盖。外部文件传输成功与数据库登记是两个阶段：登记成功不证明传输成功。

## 指标口径

- 账号/机构/赛事/有效会话：数据库当前数量；会话有效不等于实时在线。
- AI调用：一条实际供应商请求一条记录，多阶段分别计；模拟独立。输入/输出已知量汇总，未知调用另列。连接测试计量但独立phase。
- 日汇总：北京时间日期，维度含账号、机构快照、模型、模式、场景；90天内按范围查询，不能从缺失历史推算全年。
- 费用：价格版本的定点估算，缺价/未知用量不为0；账单仅供应商周期总额比较。
- 额度：默认无策略；可选账号/机构日月共同约束，预占与已结算分开。人工核对保留依据，暂停只影响后续模型调用。
- 操作分布：选定范围内审计动作/结果计数，包括读操作；不能标作独立用户数或纯业务变更数。
- 文件容量：五类上传登记expectedBytes含历史和待确认；独立只读扫描另列实际字节、缺失/大小异常/未登记对象及采样时间。二者分开显示，异常不等于可删除，不授予下载权。容量时序从首次真实采样开始。
- 技术状态：无独立采集的微信服务、完整主机资源和远程备份明确待接入；不以API启动成功代替健康实测。

## 验收门槛

治理入口超级管理员门禁、旧会话撤销、最后超管保护；完整对话原因先审计后正文、顺序、凭据遮蔽、撤权；游标、CSV上限/公式防护；多阶段计量、未知和并发预占、价格历史、机构归属；审计同事务失败回滚；监控脱敏、采集异常隔离、告警确认/恢复分开；恢复隔离与过期数据处理。服务器需单独满足7天、P95基线、故障与恢复、真实通知和备份演练。
