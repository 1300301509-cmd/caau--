# 赛事执行物料（CAAU-043）

## 产品边界

本模块记录具体比赛在执行阶段准备的实物物料，例如比赛用球、奖杯、证件和横幅。它不属于办赛资质材料，也不进入总部审核流。

- 承办方按赛事新增和维护物料；每项包含名称、数量、照片及可选备注。
- 总部赛事人员只查看清单、照片、状态和变化历史，不通过、不退回、不代替承办方修改。
- 一项物料只属于一个赛事，不复制或同步到其他赛事。
- 首版进度为 `待准备`、`准备中`、`已备齐`、`有缺口`，由承办方更新。
- 照片使用私有存储，只有仍具备该赛事操作权限的身份可以查看。

## 数据与并发

物料使用客户端 UUID 实现创建重试幂等；更新和照片确认/移除使用修订号 CAS，过期写入返回 409。每次有效变化产生不可变历史快照。照片先建立上传意图，再上传内容并校验大小、摘要和真实格式，确认后才进入清单；支持 PNG/JPEG，单张最多 10 MiB，每项最多保留 20 张未移除照片。

## 权限

- 当前有效的赛事承办机构经办人：查看、新增、修改、上传和移除照片。
- 具备赛事操作权的总部赛事管理员和总部超级管理员：只读查看及下载。
- 撤销赛事授权或承办关系后立即失去访问能力。

当前未开发小程序页面、Web 正式操作页面、物流配送、库存、签收或总部审核。
