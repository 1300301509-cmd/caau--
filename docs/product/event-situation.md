# 赛事情况

## 用户流程

总部在【比赛管理中心 → 赛事情况】按月历查看当前赛事的全部场次。有比赛的日期展示时间和对阵，点击场次后在页面中央打开详情窗口，查看比赛时间、场地、相关工作人员及两支参赛球队的人员名单。

## 数据边界

- 月历场次直接读取当前赛事的赛程编排，不另建重复比赛记录。
- 参赛人员名单属于 `EventTeam`，是本届赛事球队的独立资料；球队主档案或未来小程序球队资料变化不会自动覆盖它。
- 工作人员属于具体赛程版本中的具体场次。承办方只能对已发布的当前赛程登记，重新编排和发布后不会把旧人员误挂到新场次；旧版本保留用于追溯。
- 总部与有权赛事管理员可查看；当前赛事的有效承办经办人可通过后端接口维护。总部 Web 首版只读。
- 参赛人员支持球员、教练、领队、医疗及其他角色；工作人员记录姓名、职责、机构、联系方式和备注。手机号可不填，填写时由后端校验。

## 首版验收

1. 无赛程时显示明确空状态；草稿赛程显示待发布标识。
2. 月份前后切换不改变赛程数据，场次按日期和时间排列。
3. 点击场次打开居中详情窗口，工作人员、主队人员和客队人员分区显示；缺数据时显示局部空状态。
4. 后端按赛事逐请求鉴权，承办方写入使用 revision 防并发覆盖，总部写入与其他承办方访问被拒绝。
5. 390px 窄屏不产生整页横向滚动；月历保留日期和场次数，详情内容改为单列。

## 暂不包含

比分、技术统计、实时比赛状态、裁判排班算法、人员账号绑定、Excel 导入及小程序录入页面不在本阶段范围。
