# CAAU-005 模板文件管理与授权下载

范围：`d125828` 后的真实模板文件首版，决策见 [ADR-0007](../adr/0007-template-file-snapshots.md)。模板是总部发布任务中一项材料要求的可选附件，和承办方材料分别建模、分别鉴权。

## 已实现

- 总部赛事管理员在任务 DRAFT 中按材料创建意图、上传二进制、确认或移除模板；单项最多一个，替换需明确移除旧草案关联。失败/未确认文件不能发布，页面有带下一步的错误提示。
- `TemplateUpload` 使用 UUID storageKey、安全处理过的原文件名、扩展名/字节/SHA-256/确认状态；`TemplateAttachment` 在发布事务关联到 `RequirementVersion`。模板快照和已确认元数据受数据库触发器保护，发布后不能替换或删除。
- 每次下载 info/content 都在服务端鉴权。仅当前被指派任务的 active ORGANIZER 可读取已发布快照；总部管理员、审核员、SYSTEM_ADMIN、其他机构、撤权旧经办人、无令牌和没有快照关联的模板均拒绝。下载维持 `octet-stream`、`no-store`、`nosniff` 和安全 UTF-8 文件名；存储路径从不使用文件名。
- Web 草案配置显示每项模板状态/安全名称和发布冻结提示；承办 Web 和 Taro 详情显示模板名称并调用受控下载。复用要求配置不复制模板文件；模板不是跨任务模板库。

## 实际验证

隔离 `db:test` 的真实 PostgreSQL/API/Chromium 28 项通过：错误字节上传、确认失败、发布阻断、上传/确认、发布快照、发布后创建/移除拒绝、跨机构/审核员/system/总部下载拒绝、交接撤权、同机构新经办人读取、提交历史继续读取；浏览器从总部配置上传模板，到承办 Web 显示并以正确名称下载。额外运行 `check`、三应用 `build`、32 项 `test` 和 3 项原 Web E2E。

dev 以追加迁移升级后，记录旧迁移 checksum、已有业务表/对象摘要；不 reset、不删卷、不改旧 V1/V2。证据仅放忽略的 `.local/evidence/caau-005-template-files/`，不提交令牌、演示文件或数据库内容。

## 微信开发者工具/真机仍需用户资源

1. 一个可用于开发者工具的微信小程序 AppID，及把当前开发人员加入项目成员后的登录授权；不能用本地身份入口冒充正式微信登录。
2. 开发/体验环境可访问的 HTTPS API 域名、下载同域/API 域名及微信后台的合法 request/downloadFile 域名备案（如采用独立文件域名也需对应配置）；本机 `127.0.0.1` 不可作为真机域名。
3. 至少一个已授权测试微信号和一台可调试真机；如有组织网络/VPN/代理限制，请提供测试路径而非凭据。
4. 真实或经批准的脱敏模板样本（txt/pdf/png/jpg/jpeg）及每种格式的验收口径；不需要发送生产材料、会话、数据库或密钥。若要验收超出当前五种格式或 10 MiB 的模板，需先确认业务规则。

仍不包括：模板库、模板版本升级/跨任务复用文件、恶意文件扫描、生产对象存储与备份、正式微信 OAuth、远程 CI/部署和独立安全评审。
