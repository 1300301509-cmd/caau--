# CAAU-012 C：单份材料 Web 交互与验收设计

C阶段已完成本地Web验收；演示、截图与验证结果见 [Web手册](../runbooks/individual-material-web.md)。基线 e73e577，沿用 [ADR-0008](../adr/0008-individual-material-review.md)，不新增业务规则或修改迁移。

- 新入口 `/materials`：本地会话导入、当前身份/连接状态、任务与状态筛选、固定页码队列、选中材料详情。承办可自由新增；审核员默认待审核/审核中共享队列。保留 `/workspace` 管理入口，另在新页提供真正只读的旧整包版本入口。
- 详情分权威状态/版本/时间线与本地编辑区。文字、类别、名称、附件独立保存；确认上传后才能绑定，正式提交不替用户保存。退回原因/修改要求在表单内填写，开始审核、提交、通过/退回有显式确认，弹窗固定发起时的 revision/submissionId，后台更新不得悄悄重定向审核目标。
- 页码/筛选在轮询时不重置；新建、切换材料和打开旧历史若有未保存输入先确认放弃。同步不重新挂载表单，不抢焦点。远端草稿改变时保留输入，显示本地与权威版本，用户显式核对后可沿用输入再保存或采用远端内容。
- 无平台依赖协调器放 api-client；顺序短轮询，完成后约2秒再请求，不重叠；失败退避到30秒。每批先读取并显示已鉴权快照，再并行读取身份/任务范围，必要时补历史；历史不阻塞权威状态展示。连接标识在完整核对后恢复；后台暂停，回前台/网络恢复立即重查。每次会话、选择、生命周期变更递增epoch，迟到响应不得复活旧内容，材料修订不得倒退。
- 401 清除全部受保护状态并停止轮询；403 清除目标内容、输入、文件缓存和历史，再重查剩余范围。网络失败保留上次数据显示断线，但禁写；已授权且已下载文件不能被追回。未保存输入只在有权的当前页内存中保留，不写 localStorage。
- 未知正式命令结果保留原key/载荷，恢复后显式重试；不能把同步看到状态变化当作自己的命令成功。旧历史组件也受同一轮询、失效清理和下载epoch约束。
- 沿用 AntD6/现有蓝色后台、系统中文字体、浅色高对比和44px触控目标，不引入营销Hero或远程字体。UI技能检索中的简洁后台/React effect cleanup适用，Hero推荐不适用；React官方useEffect清理/忽略过时响应文档已核对。

验收使用真实隔离PostgreSQL、HTTP、生产Web构建及承办/审核甲/审核乙独立Chromium contexts。分别记录完整五态V1→退回→V2→通过、并发409、未保存输入、断线恢复、401/403清理、跨机构、附件与旧历史；只在故障场景延迟/丢弃真实响应，不mock成功业务。

延迟用同机单调时钟记录写HTTP响应完成至其它会话DOM达到目标状态（帧级检测，不用逐渐退避的断言轮询充当时间戳），报告样本量/p50/p95/max；不是精确数据库commit时间，也不是生产SLA。保留截图（不含会话令牌）和可重复演示脚本。旧浏览器回归、新版多会话验收、Taro构建、微信工具/真机分别报告。
