# 承办方小程序：我的比赛（CAAU-052）

入口：登录 → 首页选择赛事 → 我的比赛。主模块下有球队管理、赛程编排、物料管理、赛事情况、人员管理。当前赛事 ID 随路由传递，返回首页可切换赛事；不新建球队端小程序、不引入球队账号或扩大后端权限。

## 模块及操作

| 子模块   | 可用页面操作                                                           | 关键边界                                                                         |
| -------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 球队管理 | 本赛事球队、球队档案、从档案添加、录入、编辑、移出/恢复、归档          | 修改档案不覆盖赛事快照；退出保留历史，已有赛程会产生不可用球队冲突               |
| 赛程编排 | 北京时间周列表、日期跳转、编排条件、候选生成、逐场调整、冲突提示、发布 | 复用服务器算法和校验；重新生成/调整已发布赛程会生成草稿，旧人员安排不自动复制    |
| 物料管理 | 名称、数量、准备进度、照片上传/查看/移除、历史、搜索筛选               | 承办方维护、总部查看；私有照片不得使用公开 URL；最多20张，每张 JPG/PNG ≤10MB     |
| 赛事情况 | 按日期查看场次、工作人员与参赛名单、维护球队参赛名单                   | 参赛名单属于本赛事球队，修改影响相关场次，不是只改当前场次；工作人员跳转人员管理 |
| 人员管理 | 沿用 CAAU-051 名单与单场安排                                           | 只有已发布赛程可安排单场工作人员                                                 |

所有写入仅通过 `@caau/api-client` 调用既有受保护接口。普通查看权不自动赋予比赛管理权；具体规则见[球队管理](team-management.md)、[赛程编排](event-scheduling.md)、[物料接口](event-supplies.md)及[人员管理](event-staff.md)。

## 冲突、重试和照片

- 编辑使用打开表单时的 revision；409 保留输入，不自动覆盖其它人修改。退出编辑需确认，刷新核对后重新编辑。
- 新建球队/物料与赛程命令在结果不明时锁定原载荷，重试复用原 ID/commandId。不会每点一次“重试”就产生新命令。离开页面后尚未确认的结果需先刷新核对，避免重新创建。
- 物料照片按建立意图 → 上传字节 → 确认三个步骤执行。同一页面失败后可原请求重试。暂停或离开后，清单中的待确认照片可重新选择原文件继续，后端核对哈希和大小；不自动将待确认文件计作成功。当前后端只支持移除已确认照片，未确认意图保留待续传。
- 照片内容通过鉴权接口获取，预览文件只写入小程序沙箱；页面卸载、身份切换或权限拒绝时清理本页缓存。
- 401 清理登录态，403 清理本页数据；旧身份的未完成请求不能回写新页面状态。

## 本地体验

物料图片：进入“我的比赛 → 物料管理 → 新增物料/编辑”，填写名称、数量后点击“保存并上传图片”，即可拍照或从相册选图。也可“仅保存物料”，稍后从清单的“上传图片 / 拍照”添加。取消选图保留已保存的物料；上传显示准备、传输、校验阶段，确认完成才标为已上传。失败可重试同一上传，已上传图片继续支持受控预览及移除。格式为JPG/PNG，单张最多10MB、每项最多20张（含待确认图片）。

沿用 `CAAU_IDENTITY_MODE=local corepack pnpm db:api` 与 `corepack pnpm --filter @caau/miniapp build`。微信开发者工具打开 `apps/miniapp`；本地联调入口选择承办方身份。正式微信登录、AppID、合法域名及真机验收另行进行。

## CAAU-053 界面更新

首页进入“我的比赛”后可在赛事卡片切换赛事，查看真实概览、五个业务入口及近期赛程；近期比赛可直接打开场次详情。赛程页点选日期查看当天，再点一次恢复全周。工作台读取失败不显示假零值，权限不足时清除业务数据，可返回首页选择赛事。视觉与信息结构见[工作台设计](../product/miniapp-competition-design.md)，实际验收见roadmap。
