# 承办方小程序：我的比赛（CAAU-052）

入口：登录 → 首页选择赛事 → 我的比赛。主模块下有球队管理、赛程编排、物料管理、赛事情况、人员管理。当前赛事 ID 随路由传递，返回首页可切换赛事；不新建球队端小程序、不引入球队账号或扩大后端权限。

## 模块及操作

| 子模块   | 可用页面操作                                                                | 关键边界                                                                           |
| -------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 球队管理 | 赛事竞赛组别、本赛事球队、球队档案、从档案添加、录入、编辑、移出/恢复、归档 | 新增参赛队伍先选同赛事组别，旧队伍待人工归组；修改档案不覆盖赛事快照，退出保留历史 |
| 赛程编排 | 北京时间周列表、日期跳转、编排条件、候选生成、逐场调整、冲突提示、发布      | 复用服务器算法和校验；重新生成/调整已发布赛程会生成草稿，旧人员安排不自动复制      |
| 物料管理 | 名称、数量、准备进度、照片上传/查看/移除、历史、搜索筛选                    | 承办方维护、总部查看；私有照片不得使用公开 URL；最多20张，每张 JPG/PNG ≤10MB       |
| 赛事情况 | 按日期查看场次、工作人员与参赛名单、维护球队参赛名单                        | 参赛名单属于本赛事球队，修改影响相关场次，不是只改当前场次；工作人员跳转人员管理   |
| 人员管理 | 沿用 CAAU-051 名单与单场安排                                                | 只有已发布赛程可安排单场工作人员                                                   |

所有写入仅通过 `@caau/api-client` 调用既有受保护接口。普通查看权不自动赋予比赛管理权；具体规则见[球队管理](team-management.md)、[赛程编排](event-scheduling.md)、[物料接口](event-supplies.md)及[人员管理](event-staff.md)。

首页和“我的比赛”的赛事选择器使用`GET /api/v1/competition-events`，只列出当前身份可操作球队、赛程、物料、赛事情况和人员管理的赛事。赛事基本信息只读授权不会进入该清单。若本机保存的旧赛事已撤权或仅可查看，进入工作台时自动切换到第一场可管理赛事；没有任何可管理赛事时提示先完成赛事获批与承办指派，不继续请求子模块。

## 整套候选赛程预览（CAAU-064）

仅在统一助手中**已确认且未失效**的独立需求单下，核对当前全部有效参赛球队与具体日期、每天时段、场地、时长、缓冲和最短休息；可显式沿用当前赛事配置或完整填写，不猜业务默认值。若现有草稿需明确逐场固定范围；当前已发布/淘汰赛基线不重排。点击“仅计算候选，不保存赛程”只产生独立预览：北京时间逐场列出新旧时间/场地、受影响场次、硬条件校验与偏好说明，并区分合规/确定冲突/未找到。版本或参赛变更旧候选 `STALE`，恢复和发送模型前重新鉴权；没有正式保存/发布入口。见[候选规格](../product/agent-schedule-candidates.md)。weapp/Node 构建不代表已执行 `wx.request`、微信开发者工具或真机验收。

## 排程需求收集（CAAU-063）

已登录业务页的统一助手支持明确的整周排程需求（赛事日期、当前赛事参赛球队可用/不可用时段、两队对阵偏好），与原赛程查询及单场改期任务分开。逐项显示具体日期、MUST/PREFER、原话来源、待补、明显矛盾与当前 revision；“仅确认需求（不生成赛程）”只更新需求确认状态，不产生预览或执行票据。修改或取消要求后原确认失效；参赛记录停用时提示重新整理。遇同名参赛球队须点选择候选；409 后刷新会话，撤权清理旧内容。浏览页面的赛事不自动覆盖进行中任务。与 Web 共用 Nest 生成客户端，具体边界见[需求规格](../product/agent-schedule-planning.md)和[Agent 手册](agent-platform.md)。微信开发者工具交互、`wx.request` 与真机**未**因 weapp 构建及隔离 Node/浏览器回归而通过。

## 赛程只读查询（CAAU-062）

小程序全局助手与 Web 使用同一 `@caau/api-client` 契约和服务器只读工具；可询问授权赛事的日期／球队比赛列表与单场详情，回答须含赛事、北京时间日期、草稿／已发布和版本。遇歧义用候选明确选择；查询不修改单场任务或确认票据。撤权后历史不能继续显示或进入模型；需要返回并重新鉴权。weapp 构建和 Node 传输替身只证明代码与契约，`wx.request`／微信开发者工具及真机仍须按平台实测，不把它们写成已通过。

## 赛程调整助手（CAAU-049 C1）

在已登录的首页、我的及业务页面点击固定悬浮“智能助手”，进入统一的 CAAU 智能助手页面（登录/健康诊断页没有入口）。赛程编排页也使用此入口，不再内嵌第二套对话。浏览页面路由 `event` 只提供上下文提示，无赛事时不默认选赛事；进行中任务保持其绑定赛事并标明与当前页面的差异。可从有权赛事选择器明确切换对话，或点“新任务”清理旧条件。CAAU-060 后不选赛事也可问候、讨论赛制/排程思路；普通聊天只存 turn，不创建业务任务。只有明确单场改期才沿用当前登录经办人和选定赛事进入任务；讨论整周重排不会执行排程；明确收集需求时仅进入上述独立需求单，登记俱乐部仍不能代办，不得误触发单场预览。输入“把周六第二场移到周日”，按缺参提示继续“上午十点”或选择明确候选比赛；修改前/后及确定性冲突先作为**纯预览**展示。只有在票据有效且赛程版本未变化时点击“确认保存草稿”才执行单场改期；“取消本次确认”不执行调整。模型不指定身份、不发布赛程；本批不支持用自然语言改换场地，场地保持原值。发布仍由原赛程页人工操作。

点“最小化并返回页面”只关闭对话，不取消确认；本次登录内存保留未发送输入，重开或点“刷新任务与回执”会用当前身份重新列出有权会话，展示原 commandId、执行时 DRAFT 版本/时间及另行读取的赛程当前状态；两者可能不同。重复点击由本页锁保护；响应未知时先查持久回执，未找到才允许使用原票据重试，不签发另一写命令。歧义候选在返回页面后须重新发送原描述以重新加载选择项，不会自动选择。401/403 清除本页数据；切换账号清理全部内存；显式切换赛事新建/选择对应会话且不带入旧条件或票据；409、过期或版本变化须刷新赛程并重新生成预览，不直接重放失效票据。

本地数据库/API/Node 传输替身及微信开发者工具、真实千问、真机的证据分开记录于 [roadmap](../planning/roadmap.md)。构建完成不代表微信工具或真机写入验收通过。要手动点击新的统一页面，先按[数据库手册](database-contract.md)单独准备隔离的可丢弃合成赛事库和有权测试账号，API 仅连接该库并监听独立本地端口；用 `TARO_APP_API_BASE_URL=http://127.0.0.1:3100 corepack pnpm --filter @caau/miniapp build` 编译后在微信开发者工具打开 `apps/miniapp`。**不要**把 `db:test` 已退出并清理的临时库当作可供工具继续访问的库，不要改接开发/生产真赛事验证草稿写入。工具内应逐步核对首页/我的/多个业务页的单入口、无上下文和跨赛事提示、多轮补参及候选、最小化/返回恢复输入、纯预览、取消/确认后仅 DRAFT、撤权/冲突/过期、持久回执及重复确认；分别记录 `wx.request`、真机、真实模型证据，不把 Node fetch 替身当成微信通过。

## 冲突、重试和照片

- 编辑使用打开表单时的 revision；409 保留输入，不自动覆盖其它人修改。退出编辑需确认，刷新核对后重新编辑。
- 新建球队/物料与赛程命令在结果不明时锁定原载荷，重试复用原 ID/commandId。不会每点一次“重试”就产生新命令。离开页面后尚未确认的结果需先刷新核对，避免重新创建。
- 物料照片按建立意图 → 上传字节 → 确认三个步骤执行。同一页面失败后可原请求重试。暂停或离开后，清单中的待确认照片可重新选择原文件继续，后端核对哈希和大小；不自动将待确认文件计作成功。当前后端只支持移除已确认照片，未确认意图保留待续传。
- 照片内容通过鉴权接口获取，预览文件只写入小程序沙箱；页面卸载、身份切换或权限拒绝时清理本页缓存。
- 401 清理登录态，403 清理本页数据；旧身份的未完成请求不能回写新页面状态。

## 本地体验

物料图片：进入“我的比赛 → 物料管理 → 新增物料/编辑”，填写名称、数量后点击“保存并上传图片”，即可拍照或从相册选图。也可“仅保存物料”，稍后从清单的“上传图片 / 拍照”添加。取消选图保留已保存的物料；上传显示准备、传输、校验阶段，确认完成才标为已上传。失败可重试同一上传，已上传图片继续支持受控预览及移除。格式为JPG/PNG，单张最多10MB、每项最多20张（含待确认图片）。

沿用 `CAAU_IDENTITY_MODE=local corepack pnpm db:api` 与 `corepack pnpm --filter @caau/miniapp build`。微信开发者工具打开 `apps/miniapp`；本地联调入口选择承办方身份。正式微信登录、AppID、合法域名及真机验收另行进行。

## 验收记录

CAAU-055：移除图片返回`REMOVED`属于合法响应，客户端契约已补齐。此前若移除后出现“接口响应格式不符合生成契约”，后端可能已完成移除；更新小程序构建后刷新清单即可核对，不要据旧页面认定图片仍存在。真实API移除/刷新/幂等重试已验证，平台点击验收单独记录。

实际检查结果集中记录于 [roadmap](../planning/roadmap.md)。构建与单元测试不等于各模块微信写入闭环通过；不得为了展示自动改写开发库既有球队、赛程和物料。

## CAAU-053 界面更新

首页进入“我的比赛”后可在赛事卡片切换赛事，查看真实概览、五个业务入口及近期赛程；近期比赛可直接打开场次详情。赛程页点选日期查看当天，再点一次恢复全周。工作台读取失败不显示假零值，权限不足时清除业务数据，可返回首页选择赛事。视觉与信息结构见[工作台设计](../product/miniapp-competition-design.md)，实际验收见roadmap。
