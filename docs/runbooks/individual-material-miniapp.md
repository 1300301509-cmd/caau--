# CAAU-012 D：Taro 小程序操作与平台验收

状态：Taro源码、平台适配、构建/测试及真实后端回归已完成；**本轮微信开发者工具新版业务流程和真机流程均未通过验收**，原因见第3节。总部审核继续使用Web `/materials`，小程序只提供承办方能力。

## 1. 页面与操作

底部入口仍为“待办、赛事、我的”：

- **待办**：优先显示待提交/退回修改的单份材料，同时保留可进入的独立材料任务和旧整包任务。
- **赛事**：按赛事筛选任务，查看单份材料的五态和版本，进入任务详情。
- **我的**：载入/退出本地测试身份及工程连接检查。当前不是正式微信登录，令牌只留小程序进程内存，不写Storage。
- **任务详情**：新版任务可自由新增，编辑名称/类别/说明，选择并上传私有附件，保存后绑定，单份提交；显示审核进度、退回原因/修改要求、实际操作人和时间、不可变提交与CREATE/SAVE动作快照，并按原权限下载当前/历史附件。旧任务继续进入原整包页面，不伪造旧逐份审核。

平台随机数由 `Taro.getRandomValues` 生成后显式交给共享协调器；正式命令确认时固定revision/幂等键。未知结果不会自动重放，只能沿用原命令显式核实/重试。文件支持txt/pdf/png/jpg/jpeg、单个10MiB；图片使用预览，其他文件写入小程序沙箱后交系统文档查看器，平台实际支持范围仍须设备验证。

## 2. 自动同步和保护

详情复用 `@caau/api-client` 的平台无关 `IndividualWorkspace`：前台顺序短轮询，完整批次结束约2秒后再次读取；后台/页面隐藏停止，`useDidShow`立即重新核对。`onNetworkStatusChange`断网时保留已显示状态和未保存输入但禁写，恢复后立即核权。列表页使用相同调度原则，失败退避到30秒。

- 权威材料状态与本地编辑缓冲分离；轮询、分页不覆盖输入。另一会话保存后显示冲突，需显式选择保留本地输入或采用服务器草稿。
- 换材料、重新新增及离页对未保存输入/未知命令进行确认；环境不支持离页提醒时显示明确警告。
- 401清空全局会话和受保护页面；403或草稿权限降级清空目标、意见、历史、附件引用及输入，再核对剩余范围。session/request/lifecycle epoch阻止迟到读取或文件结果复活旧内容。
- 附件元数据和字节均逐次鉴权；令牌只放Authorization header，不进入URL。已由用户保存到设备的字节无法在事后撤回。

### 3.2 微信开发者工具实际流程：本轮受阻，未通过

现场只读核对：官方ARM64稳定版 `2.01.2510260` 仍安装；跟踪配置仍为 `touristappid`、`urlCheck=true`，无 `project.private.config.json`。当前构建origin为模拟器用 `http://127.0.0.1:3000`；仓库/本机未发现已确认的公网HTTPS测试API、受信证书/隧道或微信request合法域名。测试身份仍是本地opaque会话，不是微信身份。

本轮已实际重建 `dist/`，随后分别调用官方CLI `auto` 和 `miniprogram-automator.launch` 打开当前工程；两者均在运行页面前被开发者工具拒绝，明确报告“IDE service port disabled”。尝试通过CLI标准输入确认未生效；没有绕过工具设置、读取微信账号或修改私有配置。因此本轮没有取得新版“待办/赛事/我的”、文件选择、上传、回前台、断网或完整业务路径的开发者工具运行证据。CAAU-010历史上的游客无会话三页渲染结果只保留为旧证据，不折算为本轮新版页面通过。

即使启用服务端口，`touristappid`、无组织项目权限和无合法HTTPS仍会阻止有权业务、预览/上传及真实域名验收。本轮未把本地关闭域名校验写进项目配置。

当前不具备以下必要条件，故没有扫码、预览、体验版、上传或设备截图：

## 4. 下一轮手机体验步骤

资源就绪后按以下顺序，不手改数据库：

1. 有权成员在开发者工具“设置→安全设置”开启服务端口；为 `apps/miniapp` 选择组织AppID，确认当前账号是项目成员。AppID保留在忽略的私有配置，不改仓库的游客占位。
2. 提供公开测试API origin（只需非秘密URL），部署当前提交到隔离测试环境；在微信后台配置同一origin为request合法域名。以 `TARO_APP_API_BASE_URL=https://... corepack pnpm --filter @caau/miniapp build` 重建。
3. 用 `corepack pnpm materials:demo` 或正式管理API**追加**合成赛事、空任务和承办身份；不reset、不删除卷、不复用生产材料。将短期测试令牌通过组织批准的安全方式导入设备“我的”，不要经聊天发送。若要求正式微信登录，先另行实现并验收身份映射。
4. 开发者工具先走：待办/赛事→自由新增→附件选择/确认→保存→V1提交；总部Web开始并退回；小程序切回前台看到意见→修改保存→V2重交；总部Web通过；小程序查看动作/不可变V1/V2并下载附件。
5. 在开发者工具分别实测：隐藏/显示立即核对、断网保留输入且禁写、恢复核权、会话失效清空、赛事撤权清空、另一会话修改时输入保留；记录Network和不含秘密的截图。
6. 再在每台授权真机重复主流程与上述恢复场景，记录机型类别、系统/微信版本、网络类型和结果；至少验证一次txt/pdf和一次图片预览。开发者工具结果不替代真机，iOS结果也不自动代表Android。

总部始终使用现有Web审核；本阶段不增加小程序总部审核、报名、支付或俱乐部。
