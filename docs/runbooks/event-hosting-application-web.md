# 总部 Web 承办申请审核

状态：CAAU-027 C总部Web及D承办方小程序源码均已完成本地验收；CAAU-028审核中心新设计已取代旧版壳层并完成合并回归，当前统一开发入口为5175。小程序文件平台闭环和真机仍未通过。

## 1. 访问与边界

本地入口：<http://127.0.0.1:5175/hosting-applications>。

页面使用CAAU-028赛事审核中心壳层：单一主导航、承办申请/办赛材料两个审核入口、真实概况卡、搜索/六类筛选/分页、审核结论和最近提交；详情在独立滚动弹层打开。完整视觉与信息结构见[审核中心设计](../product/review-center-design.md)。只有后端返回有效承办申请审核能力的身份才显示队列；承办申请经办权限、赛事授权或普通`SYSTEM_ADMIN`不能替代审核权限。页面隐藏不是安全边界，列表、详情、附件和每个审核命令仍由API逐请求鉴权。

页面保留申请详情、不可变提交版本、相邻版本字段/附件变化、审核历史、受控附件下载及显式开始/补充/驳回/通过。打开详情无写副作用；开始审核不独占。正常5秒自动核对不显示技术同步栏，只有持续请求失败、409冲突、会话失效或失权才显示简洁提示。补充要求或驳回原因使用受控输入，失败和冲突时不清空。

C阶段不包含承办方申请页面；该页面现由D阶段小程序提供。正式登录、通知、新业务规则和生产部署仍不包含。

## 2. 本地启动

使用固定 Node.js 24.20.0 / pnpm 10.32.1。首次把包含 CAAU-027 的旧 dev 库升级到当前版本时，只执行前向迁移：

```sh
corepack pnpm db:migrate:deploy
corepack pnpm db:migrate:status
CAAU_IDENTITY_MODE=local corepack pnpm db:api
# 另一终端
corepack pnpm dev:admin
```

不得 reset 数据库、删除数据卷或修改历史迁移。API 预期监听 `127.0.0.1:3000`，Web 监听 `127.0.0.1:5175`。

## 3. 合成演示准备

首次准备需要按[后端手册](event-hosting-applications.md#3-首个本地超级管理员)建立本地超级管理员并签发仍有效的本地会话。随后运行：

```sh
corepack pnpm hosting:demo
```

脚本只连接回环 API，通过真实受保护接口完成：

- 向固定“总部审核员甲/乙”授予独立申请审核权限；
- 向固定承办方 A/B 经办人授予申请办理权限；
- 上传明确写有“合成”的 PDF/JPG 测试附件；
- 准备待审核、审核中、待补充、已驳回、补充后 V2 获批五种申请。

业务状态不直接写数据库。脚本把不含令牌的应用 ID 索引写入被忽略的 `.local/db/hosting-demo.json`；索引存在时只通过 API 复核，不重复造数。全部名称以 `【合成演示】` 开头，不代表真实赛事或机构资料。

## 4. 逐步体验

### 4.1 列表、详情与 V2 获批结果

1. 打开 `/hosting-applications`，选择“总部审核员甲”并进入。
2. 依次切换待审核、审核中、待补充、已通过、已驳回；核对名称、申请机构、赛事日期和提交时间。
3. 在“已通过”选择“【合成演示】CAAU-027 C 补充后 V2 获批（V2）”。
4. 查看赛事地点、办赛经验、营业执照、现场照片、V1→V2 名称变化和审核历史。
5. 点击附件“下载”，页面应显示明确成功结果。
6. 右侧获批结果应只显示一个正式赛事入口，并同时显示承办机构和“本申请 · V2”来源。

### 4.2 甲开始、乙接续

1. 甲选择待审核申请，点击“开始审核”并确认；页面提示开始不独占。
2. 在另一个标签页选择“总部审核员乙”，打开同一申请；可在刷新或下一次静默核对后看到“审核中”。
3. 乙选择“要求补充”或“驳回”；原因留空时不能提交，填写后才可确认。
4. 操作成功后状态、实际操作人、服务器时间和目标版本出现在审核历史。

演示数据是可写业务数据。若需保留五态展示，优先体验专门的待审核/审核中项，不修改已通过项；重复准备命令不会覆盖已被体验修改的状态。

### 4.3 权限与异常

- “承办方 B 经办人”进入该路由时不显示审核队列，并显示无审核权限提示。
- 两个审核员对同一审核中版本并发形成结论时，只有一个成功；失败页刷新到权威状态并保留已填写意见，显示 409 冲突提示。
- 审核权限被撤销或会话失效后，页面清理申请详情和列表；本地正在填写的意见不因普通网络错误或 409 被清空。
- 正常自动更新不显示连接、轮询或最近同步时间。
